# Easy ILP: Linux in einer VM

## Ziel

Du installierst oder erkundest Linux in einer virtuellen Maschine.

Am Ende hast du:

- eine kurze Begründung für eine Linux-Distribution
- erste Systeminformationen
- erste Terminal-Befehle
- einen Vergleich mit deinem Alltagssystem

## Was du brauchst

- Virtualisierungssoftware
- Linux-ISO oder vorhandene Linux-VM
- Notiztool

## Basis-Aufgaben

### Aufgabe 1: Wähle eine Linux-Distribution

1. Wähle eine Distribution, zum Beispiel Ubuntu oder Linux Mint.
2. Schreibe den Namen auf.
3. Schreibe 2 Gründe für deine Wahl.
4. Schreibe auf, ob sie für Anfänger geeignet ist.

**Fertig, wenn:** Du kannst deine Auswahl kurz begründen.

### Aufgabe 2: Starte oder installiere Linux

1. Öffne deine Virtualisierungssoftware.
2. Erstelle eine VM oder öffne eine vorhandene VM.
3. Wähle die Linux-ISO, falls nötig.
4. Starte die VM.
5. Folge den Installationsschritten oder melde dich an.
6. Notiere Probleme.

**Fertig, wenn:** Linux startet oder du hast den Fehler dokumentiert.

### Aufgabe 3: Prüfe Systemdaten

1. Melde dich in Linux an.
2. Suche den Systemnamen.
3. Suche die Linux-Version.
4. Suche Speicher- oder Hardwareinformationen.
5. Schreibe die Daten auf.

**Fertig, wenn:** Du hast wichtige Linux-Systemdaten notiert.

### Aufgabe 4: Erkunde die Oberfläche

1. Öffne das Startmenü oder die App-Übersicht.
2. Öffne den Dateimanager.
3. Öffne die Einstellungen.
4. Öffne einen Browser oder ein Standardprogramm.
5. Schreibe auf, was ähnlich wie bei deinem Alltagssystem ist.
6. Schreibe auf, was anders ist.

**Fertig, wenn:** Du kennst die wichtigsten Bereiche der Oberfläche.

### Aufgabe 5: Nutze das Terminal

1. Öffne das Terminal.
2. Gib `pwd` ein.
3. Gib `ls` ein.
4. Gib `whoami` ein.
5. Gib `date` ein.
6. Schreibe zu jedem Befehl eine kurze Erklärung.

**Fertig, wenn:** Du hast erste Terminal-Befehle getestet.

## Extra-Aufgaben

### Extra 1: Zweite Distribution vergleichen

1. Suche eine zweite Linux-Distribution.
2. Schreibe 3 Unterschiede zu deiner ersten Distribution auf.

**Fertig, wenn:** Du kennst einen einfachen Vergleich.

### Extra 2: Ordner im Terminal erstellen

1. Erstelle mit `mkdir` einen Ordner.
2. Wechsle mit `cd` hinein.
3. Prüfe mit `pwd`, wo du bist.

**Fertig, wenn:** Du hast im Terminal eine kleine Struktur gebaut.

## Reflexion

- Was war in Linux neu?
- Welcher Terminal-Befehl war nützlich?
- Was ist ähnlich wie bei deinem normalen System?

## Speichern oder Abgeben

- Speichere deine Linux-Notizen.
- Speichere deine Befehlsliste.
