# Easy ILP: Linux in a VM

## Goal

You will install or explore Linux in a virtual machine.

At the end, you will have:

- a short reason for one Linux distribution
- first system information
- first terminal commands
- a comparison with your daily system

## What You Need

- virtualization software
- Linux ISO or existing Linux VM
- note tool

## Basic Tasks

### Task 1: Choose a Linux Distribution

1. Choose a distribution, for example Ubuntu or Linux Mint.
2. Write down the name.
3. Write 2 reasons for your choice.
4. Write if it is good for beginners.

**Done when:** You can shortly explain your choice.

### Task 2: Start or Install Linux

1. Open your virtualization software.
2. Create a VM or open an existing VM.
3. Choose the Linux ISO if needed.
4. Start the VM.
5. Follow the installation steps or log in.
6. Write down problems.

**Done when:** Linux starts or you documented the error.

### Task 3: Check System Data

1. Log in to Linux.
2. Find the system name.
3. Find the Linux version.
4. Find storage or hardware information.
5. Write the data down.

**Done when:** You noted important Linux system data.

### Task 4: Explore the Interface

1. Open the start menu or app overview.
2. Open the file manager.
3. Open the settings.
4. Open a browser or standard program.
5. Write what is similar to your daily system.
6. Write what is different.

**Done when:** You know the main areas of the interface.

### Task 5: Use the Terminal

1. Open the terminal.
2. Type `pwd`.
3. Type `ls`.
4. Type `whoami`.
5. Type `date`.
6. Write one short explanation for each command.

**Done when:** You tested first terminal commands.

## Extra Tasks

### Extra 1: Compare a Second Distribution

1. Find a second Linux distribution.
2. Write 3 differences to your first distribution.

**Done when:** You know a simple comparison.

### Extra 2: Create Folders in the Terminal

1. Create a folder with `mkdir`.
2. Move into it with `cd`.
3. Check your location with `pwd`.

**Done when:** You built a small structure in the terminal.

## Reflection

- What was new in Linux?
- Which terminal command was useful?
- What is similar to your normal system?
