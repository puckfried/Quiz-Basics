# Easy ILP: Use the Linux Shell Safely

## Goal

You will practise simple shell commands in Linux.

At the end, you will have:

- a small folder structure
- created and moved files
- a short command list

## What You Need

- Linux system or Linux VM
- terminal
- note tool

## Basic Tasks

### Task 1: Find Your Way in the Terminal

1. Open the terminal.
2. Type `pwd`.
3. Write what is shown.
4. Type `ls`.
5. Write what is shown.
6. Use `cd` to enter a folder.
7. Check again with `pwd`.

**Done when:** You know where you are in the terminal.

### Task 2: Create Folders

1. Create a folder `shell_training`.
2. Move into this folder.
3. Create the folders `docs`, `tests`, and `backup`.
4. Check with `ls`.

**Done when:** Your folder structure exists.

### Task 3: Create and Show Files

1. Create a file `notes.txt`.
2. Write a short text into it.
3. Show the content in the terminal.
4. Create a second file `todo.txt`.
5. Check with `ls` that both files exist.

**Done when:** You created and displayed files.

### Task 4: Copy and Move Files

1. Copy `notes.txt` into the folder `backup`.
2. Move `todo.txt` into the folder `docs`.
3. Check both folders.
4. Write shortly the difference between `cp` and `mv`.

**Done when:** You practised copying and moving.

### Task 5: Clean Up Carefully

1. Create a test file.
2. Delete only this test file.
3. Check the file name before deleting.
4. Check with `ls` after deleting.
5. Write one safety rule for `rm`.

**Done when:** You deleted safely and wrote one rule.

## Extra Tasks

### Extra 1: Path Training

1. Move between folders several times.
2. Check every time with `pwd`.
3. Write down 3 paths.

**Done when:** You are safer with paths.

### Extra 2: Find an Error

1. Write one command wrong on purpose.
2. Read the error message.
3. Correct the command.

**Done when:** You understood one error message.

## Reflection

- Which command helps you most?
- When must you be very careful?
- What does a path mean?
