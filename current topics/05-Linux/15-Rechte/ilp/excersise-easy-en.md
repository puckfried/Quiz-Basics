# Easy ILP: Linux Permissions and Packages

## Goal

You will practise simple file permissions and package management in Linux.

At the end, you will have:

- a permission overview
- tested commands
- a small Linux daily cheat sheet

## What You Need

- Linux system or Linux VM
- terminal
- note tool

## Basic Tasks

### Task 1: Show Permissions

1. Open the terminal.
2. Create a folder `permissions_training`.
3. Create a file `test.txt` inside it.
4. Type `ls -l`.
5. Write down which permissions are shown.
6. Mark owner, group, and others.

**Done when:** You can roughly read the permission display.

### Task 2: Understand Permissions

1. Write what `r` means.
2. Write what `w` means.
3. Write what `x` means.
4. Add one example for each.

**Done when:** You know read, write, and execute.

### Task 3: Change Permissions

1. Change permissions only on your test file.
2. Use a simple `chmod` command.
3. Check again with `ls -l`.
4. Write what changed.
5. Do not set dangerous permissions.

**Done when:** You tested permissions safely.

### Task 4: Check Packages

1. Check which package manager your system uses.
2. Find information about one safe package.
3. Do not install anything without permission.
4. Write package name and purpose.

**Done when:** You found package information.

### Task 5: Create a Linux Cheat Sheet

1. Create a file `linux-cheatsheet.md`.
2. Add 5 important commands.
3. Add 3 rules for safe terminal work.
4. Add 3 notes about file permissions.

**Done when:** You have a small Linux help file.

## Extra Tasks

### Extra 1: Numeric Permissions

1. Write what 7, 6, 5, and 4 mean.
2. Explain one example like `755`.

**Done when:** You understand simple numeric permissions.

### Extra 2: Look Closer at a Package

1. Search details about one package.
2. Note version, description, and source.

**Done when:** You documented package information.

## Reflection

- Why are permissions important?
- When can `chmod` be dangerous?
- Which terminal rule will you remember?
