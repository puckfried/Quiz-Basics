# Easy ILP: Lists, Links, Images, and Forms

## Goal

You will extend an HTML page with important elements.

At the end, you will have:

- lists
- links
- an image
- a simple form

## What You Need

- code editor
- browser
- HTML project folder
- optional image file

## Basic Tasks

### Task 1: Prepare the Page

1. Open your HTML project.
2. Create or open `index.html`.
3. Write a heading.
4. Write a short introduction text.

**Done when:** Your HTML page is ready.

### Task 2: Create Lists

1. Create an unordered list with `ul`.
2. Write at least 3 list items.
3. Create an ordered list with `ol`.
4. Write at least 3 steps in it.
5. Open the page in the browser.

**Done when:** Both lists are visible.

### Task 3: Add Links

1. Add a link to a safe website.
2. Write a clear link text.
3. Add a second link to another page or file.
4. Test both links in the browser.

**Done when:** Both links work.

### Task 4: Add an Image

1. Put an image file into your project folder.
2. Add the image with `img`.
3. Add a useful `alt` text.
4. Check the image in the browser.

**Done when:** Image and alternative text are included.

### Task 5: Create a Form

1. Create a form with `form`.
2. Add a text field.
3. Add an email field.
4. Add a textarea.
5. Add a button.
6. Label all fields with `label`.

**Done when:** Your form is visible and understandable.

## Extra Tasks

### Extra 1: Extend the Form

1. Add a select field.
2. Add a checkbox.
3. Test the form.

**Done when:** Your form has more input options.

### Extra 2: Internal Navigation

1. Create a link to a section on the same page.
2. Test the jump.

**Done when:** Internal navigation works.

## Reflection

- When do you use lists?
- Why is `alt` important?
- Why do form fields need labels?

## Save or Submit

- Save your HTML files.
- Check the page in the browser.
