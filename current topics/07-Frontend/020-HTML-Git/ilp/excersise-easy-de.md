# Easy ILP: Listen, Links, Bilder und Formulare

## Ziel

Du erweiterst eine HTML-Seite mit wichtigen Elementen.

Am Ende hast du:

- Listen
- Links
- ein Bild
- ein einfaches Formular

## Was du brauchst

- Code-Editor
- Browser
- HTML-Projektordner
- optional Bilddatei

## Basis-Aufgaben

### Aufgabe 1: Bereite die Seite vor

1. Öffne dein HTML-Projekt.
2. Erstelle oder öffne `index.html`.
3. Schreibe eine Überschrift.
4. Schreibe einen kurzen Einführungstext.

**Fertig, wenn:** Deine HTML-Seite ist bereit.

### Aufgabe 2: Erstelle Listen

1. Erstelle eine ungeordnete Liste mit `ul`.
2. Schreibe mindestens 3 Listeneinträge.
3. Erstelle eine geordnete Liste mit `ol`.
4. Schreibe mindestens 3 Schritte hinein.
5. Öffne die Seite im Browser.

**Fertig, wenn:** Beide Listen sind sichtbar.

### Aufgabe 3: Füge Links ein

1. Füge einen Link zu einer sicheren Webseite ein.
2. Schreibe einen klaren Linktext.
3. Füge einen zweiten Link zu einer anderen Seite oder Datei ein.
4. Teste beide Links im Browser.

**Fertig, wenn:** Beide Links funktionieren.

### Aufgabe 4: Füge ein Bild ein

1. Lege eine Bilddatei in deinen Projektordner.
2. Füge das Bild mit `img` ein.
3. Ergänze einen sinnvollen `alt`-Text.
4. Prüfe die Anzeige im Browser.

**Fertig, wenn:** Bild und Alternativtext sind eingebunden.

### Aufgabe 5: Erstelle ein Formular

1. Erstelle ein Formular mit `form`.
2. Füge ein Textfeld ein.
3. Füge ein E-Mail-Feld ein.
4. Füge eine Textarea ein.
5. Füge einen Button ein.
6. Beschrifte alle Felder mit `label`.

**Fertig, wenn:** Dein Formular ist sichtbar und verständlich.

## Extra-Aufgaben

### Extra 1: Formular erweitern

1. Füge ein Auswahlfeld hinzu.
2. Füge eine Checkbox hinzu.
3. Teste das Formular.

**Fertig, wenn:** Dein Formular hat mehr Eingabemöglichkeiten.

### Extra 2: Interne Navigation

1. Erstelle einen Link zu einem Abschnitt auf derselben Seite.
2. Teste den Sprung.

**Fertig, wenn:** Die interne Navigation funktioniert.

## Reflexion

- Wann nutzt du Listen?
- Warum ist `alt` wichtig?
- Warum brauchen Formularfelder Labels?

## Speichern oder Abgeben

- Speichere deine HTML-Dateien.
- Prüfe die Seite im Browser.
