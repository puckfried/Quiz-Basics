# Individual Learning Phase: Lists, Links, Images and Simple Forms in HTML



## Your Goal

You will create a small HTML page where you use ordered and unordered lists, embed internal and external links, use images with meaningful attributes, and cleanly structure a simple form. In the end, you will have a functional practice page that meaningfully combines several basic HTML elements.



## What You Need

- A computer with a code editor, for example Visual Studio Code
- A web browser
- A working folder, for example `html-basics`
- An HTML file, for example `index.html`
- Optionally, a subfolder `images` for image files
- At least one image that you can save locally and embed in your page



## Time Planning

- 10 minutes: Create folder structure and basic HTML boilerplate
- 20 minutes: Build lists
- 20 minutes: Insert and test links
- 20 minutes: Embed images and check paths
- 25 minutes: Create a simple form
- 15 minutes: Extensions, review, and revision
- 10 minutes: Reflection



## Basic Tasks



### Task 1:
Create Page Boilerplate **Goal:** You prepare a clean working environment and lay the foundation for all subsequent tasks.

**Assignment:** Create a project folder and an `index.html` file within it. Create a complete HTML boilerplate with `<!DOCTYPE html>`, `html`, `head`, `title`, and `body`. Give the page a clear heading, for example, on an everyday topic like "My Learning Page", "Travel Ideas", "Hobby Overview", or "Mini-Profile". Add a short introductory paragraph below the heading.

**Expected Result / Target State:** Your HTML file can be opened in the browser and displays a meaningfully named page with a heading and a short descriptive text.



### Task 2:
Create Ordered and Unordered Lists **Goal:** You use `ul`, `ol`, and `li` to display content in a structured way.

**Assignment:** Add two different lists to your page:
- an unordered list with at least 4 entries
- an ordered list with at least 3 entries

Choose content that fits your page's theme. Examples:
- unordered list: materials, hobbies, travel destinations, tools
- ordered list: work steps, daily routine, study plan, recipe steps

Ensure each entry is meaningfully formulated. Add a suitable subheading above each list.

**Expected Result / Target State:** Your page contains at least one `ul` and one `ol` with correctly nested `li` elements and understandable content.



### Task 3:
Insert and Differentiate Hyperlinks **Goal:** You use `a` and `href` for external and internal links and recognize the difference between absolute and relative paths.

**Assignment:** Below your lists, add a "Links" section. Insert at least 3 links there:
- 2 external links to real websites with a complete URL
- 1 internal link to a second HTML file in your project, for example `contact.html` or `info.html`

Also create the linked second HTML file with a simple boilerplate and a short heading. Test all links in the browser. Label the links clearly to indicate where they lead.

**Expected Result / Target State:** You have functional external and internal links. The absolute links open a real website, and the relative link leads to a local HTML file in your project folder.



### Task 4:
Embed Images with Meaningful Attributes **Goal:** You embed an image with `img` and use `src`, `alt`, and `title` effectively.

**Assignment:** Create a subfolder `images` and save at least one image there. Embed this image in your `index.html`. Use:
- `src` with a correct relative path
- `alt` with a meaningful image description
- `title` with a short additional hint

Add a subheading above the image. Check in the browser if the image loads correctly. Then deliberately test a wrong path and subsequently restore the correct path to understand the difference.

**Expected Result / Target State:** A local image is displayed correctly on your page. The file path works, and the `alt` and `title` attributes are set meaningfully.



### Task 5:
Build a Simple Form **Goal:** You create a structured form with `form`, `label`, `input`, and `button`.

**Assignment:** Add a form section to your page that fits your theme. Create a simple form with at least:
- 2 text fields
- 1 email field or another suitable input field
- 1 submit button

Link each input field with a suitable `label`. Use meaningful labels, for example, Name, Email, Subject, Message, or Favorite Hobby. Set an `action` attribute with `#` for `form` and choose a method like `get` or `post`.

**Expected Result / Target State:** Your page contains a cleanly structured form with labeled input fields and a button. The layout is clearly readable and logically arranged in the browser.



## Extension Tasks



### Extension Task 1: Logically Expand Form

**Goal:** You extend your form with additional input options.

**Assignment:** Add at least two more form elements to your form, for example:
- a checkbox
- a radio button
- an input field for a phone number
- a date field

Ensure the labels remain understandable and the new elements fit your page's theme.

**Expected Result / Target State:** Your form contains additional, meaningfully selected input elements and remains well-organized.



### Extension Task 2: Improve Internal Navigation with Links

**Goal:** You structure your page better and use links within your own page.

**Assignment:** Assign jump targets to at least three sections of your `index.html`, for example, for lists, images, and the form. Create a small navigation at the top of the page with links to these sections. Test if the jumps work in the browser.

**Expected Result / Target State:** Your page has internal navigation that allows you to jump directly to several areas.



### Extension Task 3: Supplement Second Subpage with Image and Backlink

**Goal:** You reinforce relative linking across multiple files.

**Assignment:** Extend your second HTML file from Task 3. Add a short list, an image, or a small text block there. Also, add a backlink to `index.html`. If you embed an image, again pay attention to correct path specifications.

**Expected Result / Target State:** Your second HTML file is extended with content and connected to your start page via functional links.



## Important Notes

- Work step-by-step and test in the browser after each task.
- Pay attention to correctly spelled HTML tags and clean nesting.
- Use meaningful texts instead of placeholders like "Link 1" or "Image".
- Use relative paths for local files.
- Use full URLs with `http://` or `https://` for external websites.
- Choose an `alt` description that meaningfully reflects the image content.
- For forms, check that each `label` belongs to a matching input field.
- Save your files regularly.



## Reflection Questions

- Where did you use `ul` and `ol`, and why was this distinction meaningful?
- How do you recognize the difference between relative and absolute links in your project?
- What problems occurred with image paths, and how did you identify them?
- How did you decide which `alt` texts were appropriate for your images?
- Is your form structured in a way that is understandable to others?
- Which part of your page would you improve next if you had another 30 minutes?
