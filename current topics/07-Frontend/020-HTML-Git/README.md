# HTML II

## Kurzer Recap
- HTML wird von Browsern gelesen und ausgegeben
- `< >` -> signalisiert dem Browser hier kommt eine Info
- `<h1>`-> hier beginnt die wichtigste Überschrift
- es arbeitet mit Verschachtelung  
```html

<html>

    <head>
        <!-- Hier ist der Inhalt vom Head -->
    </head>
    <body>
        <!-- Hier ist der Inhalt vom body -->
    </body>

</html>
```
- Überschriften in HTML:
    - `h1` -> die wichtigste, sollte nur einmal existieren
    - `h2` -> etwas weniger wichtige Überschrift, kann es mehrfach geben
    - `h3-h6`-> noch weniger wichige Überschriften
    - `p` -> Absatz, zusammenhängender Textblock
    - `hr` -> Horizontale Linie

- VS Code hat sogenannte Emmets, Shortcuts um Code zu erzeugen

    - `h1` -> erzeugt `<h1></h1>`
