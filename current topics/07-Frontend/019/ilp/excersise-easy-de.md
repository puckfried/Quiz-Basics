# Easy ILP: Erste HTML-Seite

## Ziel

Du verstehst grob, wie Webseiten funktionieren, und erstellst eine erste HTML-Seite.

Am Ende hast du:

- eine einfache Erklärung zum Web
- eine Datei `index.html`
- eine erste Webseite im Browser

## Was du brauchst

- Code-Editor
- Browser
- Projektordner

## Basis-Aufgaben

### Aufgabe 1: Erkläre das Web einfach

1. Öffne ein neues Dokument.
2. Schreibe die Begriffe Browser, Server, Webseite und URL auf.
3. Erkläre jeden Begriff in einem Satz.
4. Zeichne eine kleine Skizze: Browser fragt Server an.

**Fertig, wenn:** Du kannst den Weg vom Browser zur Webseite einfach erklären.

### Aufgabe 2: Projektordner erstellen

1. Erstelle einen Ordner `erste_html_seite`.
2. Öffne den Ordner im Code-Editor.
3. Erstelle eine Datei `index.html`.
4. Speichere die Datei.

**Fertig, wenn:** Dein Projektordner und `index.html` existieren.

### Aufgabe 3: HTML-Grundstruktur schreiben

1. Schreibe die HTML-Grundstruktur.
2. Ergänze `head` und `body`.
3. Schreibe einen passenden Seitentitel.
4. Füge eine Überschrift in den `body` ein.
5. Füge einen kurzen Absatz ein.

**Fertig, wenn:** Deine HTML-Datei eine klare Grundstruktur hat.

### Aufgabe 4: Seite im Browser öffnen

1. Öffne `index.html` im Browser.
2. Prüfe, ob Überschrift und Absatz sichtbar sind.
3. Ändere den Text im Editor.
4. Speichere die Datei.
5. Lade die Seite neu.

**Fertig, wenn:** Du siehst deine Änderungen im Browser.

### Aufgabe 5: HTML sauber machen

1. Prüfe Einrückungen.
2. Prüfe öffnende und schließende Tags.
3. Ergänze einen zweiten Absatz.
4. Ergänze einen Kommentar im HTML.
5. Speichere alles.

**Fertig, wenn:** Deine Seite ist sauber und lesbar.

## Extra-Aufgaben

### Extra 1: Mini-Startseite

1. Ergänze einen Abschnitt über dich oder dein Lernprojekt.
2. Füge 3 kurze Stichpunkte hinzu.

**Fertig, wenn:** Deine Seite mehr Inhalt hat.

### Extra 2: Webseitenaufbau ansehen

1. Öffne eine einfache Webseite.
2. Schaue dir grob die Struktur an.
3. Notiere 3 HTML-Elemente, die du erkennst.

**Fertig, wenn:** Du erkennst HTML-Struktur auch auf anderen Seiten.

## Reflexion

- Was macht der Browser?
- Was ist eine HTML-Datei?
- Welcher HTML-Teil war noch schwierig?

## Speichern oder Abgeben

- Speichere deinen Projektordner.
- Speichere `index.html`.
