# Easy ILP: First HTML Page

## Goal

You will understand roughly how websites work and create a first HTML page.

At the end, you will have:

- a simple explanation of the web
- a file `index.html`
- a first webpage in the browser

## What You Need

- code editor
- browser
- project folder

## Basic Tasks

### Task 1: Explain the Web Simply

1. Open a new document.
2. Write the terms browser, server, webpage, and URL.
3. Explain each term in one sentence.
4. Draw a small sketch: browser asks server.

**Done when:** You can explain the way from browser to webpage simply.

### Task 2: Create a Project Folder

1. Create a folder `first_html_page`.
2. Open the folder in the code editor.
3. Create a file `index.html`.
4. Save the file.

**Done when:** Your project folder and `index.html` exist.

### Task 3: Write the HTML Base

1. Write the HTML base structure.
2. Add `head` and `body`.
3. Write a fitting page title.
4. Add a heading in the `body`.
5. Add one short paragraph.

**Done when:** Your HTML file has a clear base structure.

### Task 4: Open the Page in the Browser

1. Open `index.html` in the browser.
2. Check if heading and paragraph are visible.
3. Change the text in the editor.
4. Save the file.
5. Reload the page.

**Done when:** You see your changes in the browser.

### Task 5: Clean Up HTML

1. Check indentation.
2. Check opening and closing tags.
3. Add a second paragraph.
4. Add one comment in the HTML.
5. Save everything.

**Done when:** Your page is clean and readable.

## Extra Tasks

### Extra 1: Mini Homepage

1. Add a section about yourself or your learning project.
2. Add 3 short bullet points.

**Done when:** Your page has more content.

### Extra 2: Look at Website Structure

1. Open a simple website.
2. Look roughly at the structure.
3. Note 3 HTML elements you recognize.

**Done when:** You recognize HTML structure on other pages too.

## Reflection

- What does the browser do?
- What is an HTML file?
- Which HTML part was still difficult?

## Save or Submit

- Save your project folder.
- Save `index.html`.
