# Individual Learning Phase: File System, File Operations, and Working with Applications

## Your Goal

You will build a clear folder structure, work confidently with files and folders, and use simple applications to open, save, print documents, and perform calculations.

## What You Need

- A computer with access to a file system
- A File Explorer or Finder
- A text program that allows you to open and save simple documents
- A calculator on the computer
- Optionally, an available printer or the "Print to PDF" function

## Time Planning

- 10 minutes: Task 1
- 20 minutes: Task 2
- 25 minutes: Task 3
- 25 minutes: Task 4
- 20 minutes: Task 5
- 20 minutes: Extension Tasks or Rework

## Basic Tasks

### Task 1:
Build Folder Structure 

**Goal:** You understand the hierarchy of folders and create a clean basic structure.

**Instructions:**
In your workspace, create a main folder named `LearningPhase_Filesystem`.
Inside it, create these subfolders:

- `01_Documents`
- `02_Images`
- `03_Archive`
- `04_Print`
- `05_Notes`

Additionally, in the `01_Documents` folder, create two more subfolders:

- `Drafts`
- `Final`

Afterward, check the structure in File Explorer or Finder and briefly note which folder is parent and which folders are child folders.

**Expected Result / Target State:**
You have created a clearly recognizable folder hierarchy with a main folder and several subfolders.

### Task 2:
Create and Clearly Name Files and Folders 

**Goal:** You reliably distinguish between files and folders and assign understandable names.

**Instructions:**
In the `05_Notes` folder, create a new text document named `tasklist.txt` or a comparable text format.
Write at least 5 short lines into the document, for example, on these points:

- Folder created
- Files created
- Document saved
- Calculation performed
- Print prepared

Save the document.
Then, in the `01_Documents/Drafts` folder, create another document named `projectinfo`. Add the following:

- your name
- today's date
- a short sentence about the purpose of the folder structure

Ensure that you assign filenames without unclear designations like `new1`, `testtest`, or `document`.

**Expected Result / Target State:**
You have created, saved, and sensibly named at least two files. You recognize the difference between a folder and a file in your structure.

### Task 3:
Copy, Move, and Delete Files 

**Goal:** You confidently perform basic file operations.

**Instructions:**
Work with the `projectinfo` file from the `Drafts` folder.

1. Copy the file to the `03_Archive` folder.
2. Move the original file from `Drafts` to the `Final` folder.
3. In the `02_Images` folder, create a test folder named `Temp`.
4. Create any test file in `Temp`, for example, an empty text document.
5. Then delete the test file and the `Temp` folder.

After each step, check if the file is actually in the correct location.

**Expected Result / Target State:**
A copy of `projectinfo` is in the archive, the original is in the `Final` folder, and the test folder has been removed.

### Task 4:
Open, Edit, Save, and Prepare Document for Printing 

**Goal:** You work with a simple document in an application.

**Instructions:**
Open the `projectinfo` file from the `Final` folder in your text program.
Add the following content to the document:

- a heading
- a short list of 3 tasks you completed today
- a concluding sentence

Save the document under the same name.
Then, save a second version in the `04_Print` folder, for example, as `projectinfo_printversion`.
Open the print function. If no printer is available, choose to output as PDF, if possible.

**Expected Result / Target State:**
You have opened, edited, resaved a document, and placed a print-ready version in a separate folder.

### Task 5:
Perform Simple Calculations and Document Them 

**Goal:** You use the calculator and transfer results to a file.

**Instructions:**
Open the calculator and perform these calculations:

- 125 + 87
- 450 - 198
- 24 × 6
- 144 ÷ 12
- 19.99 + 5.50 + 3.20

In the `05_Notes` folder, create a new document named `calculations`.
Enter each task with its result there.
Save the file and finally open it again to check if all content is present.

**Expected Result / Target State:**
You have used the calculator, recorded several results in a file, and successfully saved and reopened the file.

## Extension Tasks

### Extension Task 1: Improve File Storage

**Goal:** You optimize your structure for even better overview.

**Instructions:**
Extend the main folder with two additional subfolders that are useful for your daily work, for example, `06_Invoices` or `07_Templates`.
Move existing files so that each file is in a logically appropriate place.
Rename at least one file so that its name becomes even clearer and more unambiguous.

**Expected Result / Target State:**
Your storage is clear, logically structured, and contains understandable file and folder names.

### Extension Task 2: Create Archive Version

**Goal:** You securely save a processing status.

**Instructions:**
In the `03_Archive` folder, create an additional version of your `projectinfo` file, for example, with the date in the filename.
In the archive version, add a line indicating that it is an archived state.
Then open both the file in the `Final` folder and the archive version and compare the names and storage locations.

**Expected Result / Target State:**
You have a traceable archive version with a unique name and recognize the difference between an active file and an archive file.

### Extension Task 3: Create Mini-Workbook

**Goal:** You combine file storage, document editing, and calculation in a small practical task.

**Instructions:**
In the `01_Documents/Final` folder, create a new document named `dailyoverview`.
Add the following content:

- a short heading
- 3 completed tasks
- 2 calculation results from Task 5
- a sentence about which folder contains the print version

Save the document and place a copy in the `03_Archive` folder.

**Expected Result / Target State:**
You have created a complete, cleanly saved document and additionally archived it.

## Important Notes

- Pay attention to clear and consistent names for files and folders.
- Check the save location after each save.
- Do not confuse moving with copying.
- Reopen files after saving to check your work status.
- If no printer is available, use the PDF output if possible.
- Work step by step and check your results directly in the file system.

## Reflection Questions

- How do you recognize in your structure which folder is parent and which is child?
- How do you reliably recognize the difference between a file and a folder?
- At which step was the difference between copying and moving particularly important for you?
- How do clear filenames help you find content again?
- How did you proceed to prepare a document for printing?
- How did you check if your files were saved in the correct location?
