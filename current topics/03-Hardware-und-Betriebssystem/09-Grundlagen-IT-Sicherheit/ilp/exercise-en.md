# Individual Learning Phase: Everyday IT Security: Passwords, Attachments, and Secure System Maintenance

## Your Goal

You will check the security status of a system, evaluate your password practices, handle personal data sensitively, recognize risks associated with unknown attachments, and securely perform typical protection and maintenance tasks on a system.

## What You Need

- a PC or laptop with internet access
- access to system settings
- a text document, note-taking tool, or paper for your results
- optional: access to your email inbox or anonymized sample messages
- optional: permissions to run updates or uninstall programs

## Time Planning

- 10 minutes: Preparation and creating a work document
- 15 minutes: Task 1
- 15 minutes: Task 2
- 20 minutes: Task 3
- 20 minutes: Task 4
- 20 minutes: Task 5
- 15 minutes: 1–2 extension tasks
- 5 minutes: Reflection

## Basic Tasks

### Task 1:

System Security Check 

**Goal:** You gain an overview of your system's most important protective functions.

**Work Assignment:**
Open your system settings and document the following points for your system:

1. Operating system and version
2. Antivirus status
3. Firewall status
4. Time of the last system update
5. Whether updates are set up automatically or manually

Then, create a brief overview with three columns:

- Protection Area
- Current Status on Your System
- Your Assessment: "OK", "Check", "Action Required"

Add a short sentence with your own practical relevance to each of these three terms:

- Antivirus protection
- Firewall
- Software updates

**Expected Outcome / Target State:**
You have a clear documentation of your system's current security status and can distinguish the three protection areas using your own device.

### Task 2:

Securely Check and Improve Passwords 

**Goal:** You securely evaluate passwords without revealing actual login credentials and develop better password practices.

**Work Assignment:**
Create a checklist with characteristics of secure passwords. Use, among others, these checkpoints:

- sufficiently long
- not easy to guess
- does not contain personal data
- different for each service
- not visibly noted or insecurely stored

Apply your checklist to the following situation:

1. Evaluate your current password practice for at least three accounts you use, without writing down actual passwords.
2. Only note the characteristics, for example: "same password used multiple times", "too short", "contains name", "unique", "long passphrase".
3. Formulate new password rules or passphrases according to your security standard for three fictitious accounts, for example for:
   - Email
   - Online shop
   - Learning platform
4. Note how you plan to securely manage passwords in the future.

**Expected Outcome / Target State:**
You have a comprehensible password checklist, an honest assessment of your password practices, and concrete improvements for future passwords.

### Task 3:

Properly Protect Personal Data 

**Goal:** You recognize which information is particularly sensitive and define appropriate protective measures.

**Work Assignment:**
Create a table with at least ten types of personal data, for example:

- full name
- address
- phone number
- date of birth
- email address
- ID data
- bank details
- health data
- photos
- location data

Categorize each piece of information into one of three levels:

- rather uncritical
- sensitive
- particularly worthy of protection

Add to each entry:

- where this information might appear in everyday life
- what risk arises from careless handling
- how you better protect the information

Conclude the task with three short rules that you want to adhere to in the future when dealing with personal data.

**Expected Outcome / Target State:**
You have a structured overview of personal data, its protection needs, and concrete rules of conduct for everyday life.

### Task 4:

Checking Unknown Attachments and Suspicious Messages 

**Goal:** You handle unknown attachments, links, and senders cautiously.

**Work Assignment:**
Analyze at least three messages or typical examples. If you use your email inbox, anonymize the content in your documentation. If you don't want to use an inbox, describe three typical situations yourself, for example:

- Invoice with attachment from an unknown sender
- Package notification with a link
- Alleged password warning with time pressure

For each message, check:

- Sender address
- Subject
- Language and spelling
- Attachments or file extensions
- Contained links
- Call for quick action
- Handling of personal data or login credentials

Then decide for each message:

- open
- do not open
- check further first

Briefly justify your decision in each case.

**Expected Outcome / Target State:**
You have a structured risk assessment for at least three messages and can reasonably decide how to deal with unknown attachments and links.

### Task 5:

Securely Managing Programs and Updates 

**Goal:** You perform typical maintenance tasks on a system securely and comprehensibly.

**Work Assignment:**
Process the following steps in order:

1. Select an installed program and check:
   - Manufacturer
   - Installed version
   - Whether an update is available
   - Whether the source is trustworthy
2. Perform an update check for your operating system.
3. If updates are available and permitted, install them. If you don't have permissions, document exactly what you would need to do.
4. Find a program that you no longer need or haven't used for a long time.
5. Check if uninstallation is sensible. Only perform it if you are sure. If you don't want to or are not allowed to uninstall anything, describe the secure uninstallation process instead.

Finally, create a brief comparison:

- What does antivirus protection protect?
- What does the firewall regulate?
- Why are updates important?

Use a concrete example from your system or your daily work for each.

**Expected Outcome / Target State:**
You have checked the update status, performed at least one real maintenance operation or documented it clearly, and practically recorded the differences between antivirus protection, firewall, and updates.

## Extension Tasks

### Extension Task 1: Secure Installation Checklist

**Goal:** You develop a clear routine for secure software installations.

**Work Assignment:**
Create a checklist with at least eight points for secure installations. Consider, for example:

- official manufacturer's website
- check download source
- check filename and file extension
- deselect additional software
- critically read permissions
- skim license terms
- check for updates after installation
- cleanly uninstall if necessary

Apply your checklist to a real or planned program.

**Expected Outcome / Target State:**
You have a reusable installation checklist and at least one documented application.

### Extension Task 2: Security Routine for the Next 4 Weeks

**Goal:** You plan simple, realistic security measures for your everyday life.

**Work Assignment:**
Create a 4-week plan with short, concrete tasks, for example:

- Check passwords
- Control updates
- Clean up download folder
- Review unused programs
- Train email awareness

Plan 2–3 small measures per week with estimated time requirements.

**Expected Outcome / Target State:**
You have an actionable security plan that you can use directly in your daily life.

### Extension Task 3: Risk Analysis of a Typical Everyday Case

**Goal:** You apply the developed security rules to a realistic situation.

**Work Assignment:**
Choose an everyday case, for example:

- Registering for a new online service
- Downloading free software
- Receiving an email with an attachment
- Using public Wi-Fi

Describe in 5–8 steps how you proceed securely, what risks can arise, and what protective measures you use.

**Expected Outcome / Target State:**
You have a complete, comprehensible security procedure for a typical everyday situation.

## Important Notes

- Never write real passwords in your work document.
- Do not open suspicious attachments just for checking.
- Do not click unknown links if you are unsure.
- Only install software from trusted sources.
- Only uninstall programs if you are sure you don't need them.
- If you don't have admin rights on your device, document the secure procedure instead of executing it.
- When taking notes, make sure to anonymize personal data.

## Reflection Questions

- What did you discover about your system that you hadn't consciously noticed before?
- Where is your biggest security risk currently: passwords, data handling, attachments, or updates?
- What measure can you directly improve today?
- What will you do differently in the future before opening an attachment or before an installation?
- Which of your new rules is most important for your everyday life?
