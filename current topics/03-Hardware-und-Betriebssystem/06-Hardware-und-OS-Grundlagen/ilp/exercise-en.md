# Individual Learning Phase: Practical Exploration of Computer Hardware and Operating System Fundamentals

## Your Goal

You will learn about the most important hardware components of a computer, navigate confidently on your operating system's interface, and independently perform basic system settings. By the end, you will be able to use central controls, adjust simple settings, and securely perform typical basic functions in everyday use.

## What you need

- A running computer or laptop
- Access to a user account on the system
- Mouse and keyboard
- A way to write short notes, for example, in a text file or on paper
- Optional: Access to your device's system settings

## Schedule

- 10 minutes: Task 1
- 20 minutes: Task 2
- 25 minutes: Task 3
- 25 minutes: Task 4
- 20 minutes: Task 5
- 20 minutes: Extension tasks or in-depth study

## Basic Tasks

### Task 1:

Identify hardware components on your own device
**Goal:** You identify the most important parts of a computer and assign their basic function.

**Work Order:**
Examine your device closely and identify the existing hardware components. For each item, note whether you can recognize it directly on the device or if you need to look it up through the system.

Address at least these points:
- Processor
- RAM (Random Access Memory)
- Drive or storage
- Screen
- Keyboard
- Mouse or touchpad
- Ports or connected peripherals, such as USB devices, headset, printer, or external mouse

Create a brief overview with three columns:
1. Component
2. Where you found it
3. What it is broadly responsible for

**Expected Outcome / Target State:**
You have created a complete list of your device's most important hardware components and can assign a simple basic function to each component.

### Task 2:

Safely use Desktop, Start Menu, and Taskbar
**Goal:** You recognize the central controls of the operating system interface and use them consciously.

**Work Order:**
Examine your desktop and perform these steps sequentially:

- Find the desktop and briefly describe what is visible there.
- Open the Start Menu.
- Search for a pre-installed application via the Start Menu, such as Notepad, Calculator, or Settings.
- Launch two different programs.
- Observe the taskbar:
  - Which icons are permanently pinned?
  - Which programs are currently open?
- Switch between the open programs.
- Close one of the programs and leave the other open.

For each control element, write down in one sentence what you use it for:
- Desktop
- Start Menu
- Taskbar

**Expected Outcome / Target State:**
You can safely distinguish Desktop, Start Menu, and Taskbar, open programs through them, and switch between open applications.

### Task 3:

Manage windows and navigate the system
**Goal:** You control windows purposefully and move confidently between applications and areas of the system.

**Work Order:**
Work with at least two open windows, for example, Settings and Notepad, or File Explorer.

Perform these actions:
- Move a window
- Maximize a window
- Resize a window
- Minimize a window
- Restore a minimized window
- Arrange windows side-by-side
- Switch between windows
- Close a window

Then open File Explorer and navigate into at least two different folders. Use:
- Forward or Back
- Address bar or navigation pane
- Double-click or single-click depending on the system

Afterward, create a short note file titled "My System Navigation" and write 4-5 bullet points about which steps were easy or unfamiliar for you.

**Expected Outcome / Target State:**
You can purposefully control windows, switch between programs, and orient yourself fundamentally within the system and File Explorer.

### Task 4:

Adjust elementary system settings
**Goal:** You find central system settings and change simple options in a controlled manner.

**Work Order:**
Open the system settings and sequentially search for the areas for:
- Time or Date
- Language or Region
- Display or Screen

Check the currently set values and then perform at least three practical actions:
- Check timezone, time, or date format
- Check the set language or input language
- Change a display option that can be safely tested, for example, brightness, scaling, or background image
- If possible: Revert a change if you made it only for testing purposes

Record in a short table:
1. Setting area
2. What you found
3. What you changed or checked

**Expected Outcome / Target State:**
You can open the most important setting areas, find relevant options, and check or adjust at least three basic settings.

### Task 5:

Correctly execute system access and system states
**Goal:** You use basic actions for logging in and out, as well as for safely shutting down or restarting the system.

**Work Order:**
In the Start Menu or user area, find the functions for:
- Lock
- Sign out
- Shut down
- Restart

First, check where these options are located. Then perform at least one of the following actions:
- Lock the screen and unlock it again
- Sign out and sign in again

If a shutdown or restart is possible, perform one of these actions only if you have saved your work beforehand and can continue working afterward. Then note down in 3-4 bullet points:
- Where you found the options
- How Lock, Sign out, Shut down, and Restart differ
- Which action you would use in which everyday scenario

**Expected Outcome / Target State:**
You know the most important system states and can safely find the appropriate actions and practically perform at least one of them.

## Extension Tasks

### Extension Task 1: Hardware Check in the System

**Goal:** You supplement your hardware overview with information from the operating system.

**Work Order:**
Search the system for information about your device, for example, in the system settings or a device overview. Supplement your overview from Task 1 with:
- Processor name
- Size of RAM
- Name or type of drive, if visible
- Screen resolution, if visible

Then compare your observations on the device with the system information.

**Expected Outcome / Target State:**
You have supplemented your hardware overview with specific system data and recognize the connection between the physical device and the displayed system information.

### Extension Task 2: Prepare Workspace for Everyday Use

**Goal:** You set up your workspace so that you can perform typical tasks faster.

**Work Order:**
Customize your workspace in the operating system. Perform at least three of the following points:
- Pin a frequently used application to the taskbar
- Change the desktop background
- Consciously check the time or date display
- Adjust the display brightness
- Select a suitable language or keyboard input
- Use a window layout that allows you to view two programs in parallel

Then briefly write down which customization would help you most in everyday life.

**Expected Outcome / Target State:**
Your interface has been meaningfully customized in several places, and you can explain the practical benefits of these changes for you.

### Extension Task 3: Create a Mini-Documentation

**Goal:** You secure your work results in a clear format.

**Work Order:**
Create a short document titled "My Computer Fundamentals." Structure it into these sections:
- Important Hardware Components
- Important Operating System Controls
- Important Settings
- Important System Actions

Fill each section with 3-5 bullet points based on your results from the basic tasks. Save the document in a location where you can find it again.

**Expected Outcome / Target State:**
You have created your own compact overview that summarizes your most important findings and work results.

## Important Notes

- Save open files before signing out, locking the computer, shutting down, or restarting.
- Only change settings that you can understand and revert if necessary.
- If your system names terms slightly differently, continue working with the corresponding areas of your device.
- Briefly document what you found, checked, and changed.
- If you get stuck at any point, record which step you stopped at and what you have already tried.

## Reflection Questions

- Which hardware component was easiest for you to categorize?
- Which function of the Desktop, Start Menu, or Taskbar do you now use more confidently than before?
- Which window function was most practical for you?
- Which system setting was easy to find, which was less so?
- When would you lock, when would you sign out, and when would you restart?
- What else would you like to master more confidently in the operating system next time?
