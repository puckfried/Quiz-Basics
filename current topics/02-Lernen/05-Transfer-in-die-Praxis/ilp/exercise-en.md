# Individual Learning Phase: Knowledge Transfer and Reflection in Core Tech Fundamentals

## Your Goal

You will formulate your own learning objectives, apply fundamental knowledge from Core Tech Fundamentals to small practical tasks, and then evaluate how well your learning strategy works for you. By the end, you will have documented a small practice project and defined concrete next steps for your continued learning.

## What You Need

- A PC or notebook
- Access to your operating system and system settings
- A text editor or note-taking tool
- Optional: Terminal, command prompt, or PowerShell
- A browser for quick research
- A folder where you collect all your results

## Time Allocation

- 10 minutes: Task 1
- 20 minutes: Task 2
- 35 minutes: Task 3
- 25 minutes: Task 4
- 20 minutes: Task 5
- 10 minutes: Reflection and Conclusion

## Basic Tasks

### Task 1:

Define Learning Objectives **Goal:** You set clear and actionable learning objectives for this work phase.

**Assignment:** Create a short work note with 3 personal learning objectives for the next 2 hours. Use formulations that are concrete and verifiable. Refer to simple topics from Core Tech Fundamentals, such as operating system, file management, network information, user accounts, system information, or basic error analysis. For each learning objective, add:
- your current status
- why the objective is practically relevant to you
- how you will know at the end that you have achieved it

**Expected Outcome / Target State:** You have 3 clearly formulated learning objectives documented in writing, including starting point, benefit, and verifiable outcome.

### Task 2:

Select and Plan a Practical Scenario **Goal:** You transfer your learning to a simple, realistic IT work context.

**Assignment:** Choose one of the following practical scenarios or formulate a similar one of your own:
- A new workstation needs to be prepared for use and documented.
- A user reports: "My computer is slow, and I can't connect to the network."
- You need to collect the most important basic information of a system for IT documentation.

Then create a short work plan:
- What exactly is the task?
- What information do you need to collect?
- What steps will you perform sequentially?
- What tools or menus do you need for this?
- What knowledge from Core Tech Fundamentals will you use?

Record the plan in bullet points.

**Expected Outcome / Target State:** You have a selected practical scenario and a comprehensible work plan with concrete steps.

### Task 3:

Execute Mini-Project: System Basic Check **Goal:** You practically implement your plan and work with fundamental system information.

**Assignment:** Create a project folder, for example `ILP_CoreTech_Basiccheck`. In it, perform a simple basic check of your device or a provided system. Collect and document at least the following information:
- Device or computer name
- Operating system and version
- Username
- IP address or network information
- Available disk space
- Installed or active network interfaces
- Current status of the internet or network connection

Document your results in a file, for example `systemcheck.txt` or `systemcheck.md`. Briefly add for each point where you found the information or which command you used to determine it.

**Expected Outcome / Target State:** You have a project folder with a structured documentation of the system basic check and comprehensible sources or commands.

### Task 4:

Process a Simple Real Task **Goal:** You apply your knowledge to a concrete, typical support or administration task.

**Assignment:** Process one of the following tasks, appropriate to your practical scenario:

- Create a checklist "First steps for a new workstation."
- Create a checklist "Initial analysis for network problems."
- Create a short documentation "Which basic data must be collected for a device?"

Your checklist or short documentation should contain at least 8 meaningful points. Arrange the points in a logical order. Briefly explain why each point is important.

If you wish, you can additionally verify individual steps directly on your system, for example, network status, disk space, user account, or system settings.

**Expected Outcome / Target State:** You have a practical working document with at least 8 organized steps or checkpoints that can be used for a simple, real IT task.

### Task 5:

Review and Adapt Learning Method **Goal:** You analyze how you learned and derive concrete improvements.

**Assignment:** Review your previous results and answer the following points in writing:
- Which task was easy for you?
- Where did you lose time or feel unsure?
- Which learning method did you primarily use today, for example, experimenting, note-taking, reviewing, researching, working step-by-step?
- What helped you?
- What would you do differently next time?
- What 2 next learning steps do you derive from this?

Then formulate a short personal improvement plan for your next learning phase.

**Expected Outcome / Target State:** You have an honest brief reflection and a concrete improvement plan with at least 2 next learning steps.

## Extension Tasks

### Extension Task 1: Mini Knowledge Transfer to a Second Case

**Goal:** You transfer your approach to a new, similar situation.

**Assignment:** Take a second short practical scenario, for example, instead of "System Basic Check" now "Network Problem" or instead of "New Workstation" now "Device Documentation." Create a compact procedural model for this in 10 to 15 bullet points. Reuse as much as possible from your previous results, but adapt it to the new situation.

**Expected Outcome / Target State:** You have demonstrated that you can apply your knowledge not just once but transfer it to a similar task.

### Extension Task 2: Create Your Own Template

**Goal:** You develop a reusable work tool from your practice project.

**Assignment:** Create a simple template for future basic IT tasks, for example:
- a system check template
- a checklist for initial analyses
- a documentation template for device information

Ensure the template is clear and provides space for actual entries.

**Expected Outcome / Target State:** You have a reusable template that you can directly apply to similar tasks.

### Extension Task 3: Self-Test Without Aids

**Goal:** You check what you have already firmly memorized.

**Assignment:** Close your notes for 5 minutes and write down from memory:
- which system information you would collect during a basic check
- which 5 to 8 steps you would perform during a simple initial IT analysis
- which commands, menus, or tools you typically use for this

Then compare your list with your documents and mark any gaps.

**Expected Outcome / Target State:** You have performed a brief self-test and clearly recognize what you already know well and what you still need to consolidate.

## Important Notes

- Work in small, clear steps.
- Document everything so you can reuse it later.
- Do not change system settings if you do not have permission to do so.
- If a step is not possible on your device, note down instead how you would generally proceed.
- Use only as much research as you truly need, and record what you have learned anew.
- Ensure that your results are practically usable and not just theoretically formulated.

## Reflection Questions

- Which of your learning objectives have you fully achieved?
- Where were you able to apply knowledge directly in practice?
- Which task had the strongest practical relevance for you?
- Which learning method was most helpful for you today?
- What do you want to consciously maintain in your next learning phase?
- What do you specifically want to do differently to learn more effectively?
