# Easy ILP: Start Your First Virtual Machine

## Goal

You will set up virtualization software and start a first VM.

At the end, you will have:

- installed virtualization software
- one created VM
- a short start documentation

## What You Need

- PC or notebook
- virtualization software
- ISO file for an operating system
- note tool

## Basic Tasks

### Task 1: Check Requirements

1. Check if you are allowed to install virtualization software.
2. Check if your computer has enough storage.
3. Check if you have an ISO file.
4. Write down your results.

**Done when:** You know if you can start.

### Task 2: Install the Software

1. Open the official website of the software.
2. Download the correct version.
3. Install the software.
4. Start the software.
5. Write down the program name and version.

**Done when:** The virtualization software starts.

### Task 3: Create a VM

1. Click new VM.
2. Give the VM a clear name.
3. Choose the operating system.
4. Set RAM.
5. Set storage space.
6. Choose the ISO file.
7. Save the VM.

**Done when:** The VM is created.

### Task 4: Start the VM

1. Start the VM.
2. Watch the startup.
3. Follow the installation steps.
4. Stop if you are unsure.
5. Write down error messages.
6. Make a screenshot or short note of the result.

**Done when:** The VM starts or you documented the error.

### Task 5: Document the Start

1. Create a file `vm-start.md`.
2. Write down the VM name.
3. Write down RAM and storage.
4. Write down the network mode.
5. Write if the start worked.
6. Write 2 things you learned.

**Done when:** Your VM setup is documented clearly.

## Extra Tasks

### Extra 1: Compare Network Modes

1. Write down the current network mode.
2. Find a second network mode.
3. Write the difference shortly.

**Done when:** You know 2 network modes.

### Extra 2: Adjust Resources

1. Change RAM or CPU only if allowed.
2. Start the VM again.
3. Write if something changes.

**Done when:** You observed one change.

## Reflection

- What was easy during setup?
- Where were there problems?
- Which setting is very important for a VM?
