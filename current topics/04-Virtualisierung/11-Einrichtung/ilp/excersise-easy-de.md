# Easy ILP: Erste virtuelle Maschine starten

## Ziel

Du richtest eine Virtualisierungssoftware ein und startest eine erste VM.

Am Ende hast du:

- eine installierte Virtualisierungssoftware
- eine angelegte VM
- eine kurze Start-Dokumentation

## Was du brauchst

- PC oder Notebook
- Virtualisierungssoftware
- ISO-Datei für ein Betriebssystem
- Notiztool

## Basis-Aufgaben

### Aufgabe 1: Prüfe die Voraussetzungen

1. Prüfe, ob du Virtualisierungssoftware installieren darfst.
2. Prüfe, ob dein Computer genug Speicher hat.
3. Prüfe, ob du eine ISO-Datei hast.
4. Schreibe deine Ergebnisse auf.

**Fertig, wenn:** Du weißt, ob du starten kannst.

### Aufgabe 2: Installiere die Software

1. Öffne die offizielle Webseite der Software.
2. Lade die passende Version herunter.
3. Installiere die Software.
4. Starte die Software.
5. Schreibe den Programmnamen und die Version auf.

**Fertig, wenn:** Die Virtualisierungssoftware startet.

### Aufgabe 3: Erstelle eine VM

1. Klicke auf neue VM.
2. Gib der VM einen klaren Namen.
3. Wähle das Betriebssystem.
4. Lege RAM fest.
5. Lege Speicherplatz fest.
6. Wähle die ISO-Datei.
7. Speichere die VM.

**Fertig, wenn:** Die VM ist angelegt.

### Aufgabe 4: Starte die VM

1. Starte die VM.
2. Beobachte den Start.
3. Folge den Installationsschritten.
4. Stoppe, wenn du unsicher bist.
5. Notiere Fehlermeldungen.
6. Mache einen Screenshot oder kurze Notiz vom Ergebnis.

**Fertig, wenn:** Die VM startet oder du hast den Fehler dokumentiert.

### Aufgabe 5: Dokumentiere den Start

1. Erstelle eine Datei `vm-start.md`.
2. Schreibe den Namen der VM auf.
3. Schreibe RAM und Speicher auf.
4. Schreibe den Netzwerkmodus auf.
5. Schreibe, ob der Start funktioniert hat.
6. Schreibe 2 Dinge auf, die du gelernt hast.

**Fertig, wenn:** Deine VM-Einrichtung ist nachvollziehbar dokumentiert.

## Extra-Aufgaben

### Extra 1: Netzwerkmodus vergleichen

1. Notiere den aktuellen Netzwerkmodus.
2. Suche einen zweiten Netzwerkmodus.
3. Schreibe kurz den Unterschied auf.

**Fertig, wenn:** Du kennst 2 Netzwerkmodi.

### Extra 2: Ressourcen anpassen

1. Ändere RAM oder CPU nur, wenn es erlaubt ist.
2. Starte die VM erneut.
3. Schreibe auf, ob sich etwas ändert.

**Fertig, wenn:** Du hast eine Änderung beobachtet.
