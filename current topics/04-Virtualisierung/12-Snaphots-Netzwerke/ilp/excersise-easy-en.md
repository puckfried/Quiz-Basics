# Easy ILP: Use Virtual Machines Safely

## Goal

You will use a virtual machine carefully and check simple network settings.

At the end, you will have:

- a VM security list
- notes about network and snapshot
- a short export or backup idea

## What You Need

- an existing VM
- virtualization software
- note tool
- optional internet access in the VM

## Basic Tasks

### Task 1: Check the VM State

1. Start the virtualization software.
2. Choose your VM.
3. Check name, RAM, and storage.
4. Check the network mode.
5. Write everything in a file `vm-security.md`.

**Done when:** You know the most important settings of your VM.

### Task 2: Start the VM Safely

1. Start the VM.
2. Log in.
3. Check if the system runs normally.
4. Do not open unknown files.
5. Write if internet works.

**Done when:** The VM runs and you noted the state.

### Task 3: Create a Snapshot

1. Find the snapshot function.
2. Create a snapshot if allowed.
3. Give it a clear name.
4. Write why the snapshot is useful.
5. If snapshots are not possible, describe how you would make a backup.

**Done when:** You have a snapshot or a backup note.

### Task 4: Check Network Carefully

1. Check the network mode of the VM.
2. Write if the VM may access the internet.
3. Open a safe website if allowed.
4. Write if the connection works.
5. Do not change network settings without permission.

**Done when:** You checked the network connection safely.

### Task 5: Write Security Rules

1. Write 5 rules for safe VM use.
2. Include snapshots.
3. Include network mode.
4. Include unknown files.
5. Include updates.
6. Save the rules in `vm-security.md`.

**Done when:** Your VM security list is finished.

## Extra Tasks

### Extra 1: Rate Network Modes

1. Write down 2 network modes.
2. Write which one is safer for tests.
3. Give a short reason.

**Done when:** You can rate network modes more easily.

### Extra 2: Plan Export

1. Find where to export a VM.
2. Write down the steps.
3. Only export if it is allowed.

**Done when:** You know how a VM can be backed up or moved.

## Reflection

- Why are snapshots useful?
- Which network mode is useful for tests?
- Which VM rule will you always follow?

## Save or Submit

- Save `vm-security.md`.
- Save snapshot or export notes.
