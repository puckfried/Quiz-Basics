# Easy ILP: Virtuelle Maschinen sicher nutzen

## Ziel

Du nutzt eine virtuelle Maschine vorsichtig und prüfst einfache Netzwerkeinstellungen.

Am Ende hast du:

- eine VM-Sicherheitsliste
- Notizen zu Netzwerk und Snapshot
- eine kurze Export- oder Backup-Idee

## Was du brauchst

- eine vorhandene VM
- Virtualisierungssoftware
- Notiztool
- optional Internetzugang in der VM

## Basis-Aufgaben

### Aufgabe 1: Prüfe den Zustand der VM

1. Starte die Virtualisierungssoftware.
2. Wähle deine VM aus.
3. Prüfe Name, RAM und Speicher.
4. Prüfe den Netzwerkmodus.
5. Schreibe alles in eine Datei `vm-sicherheit.md`.

**Fertig, wenn:** Du kennst die wichtigsten Einstellungen deiner VM.

### Aufgabe 2: Starte die VM sicher

1. Starte die VM.
2. Melde dich an.
3. Prüfe, ob das System normal läuft.
4. Öffne keine unbekannten Dateien.
5. Notiere, ob Internet funktioniert.

**Fertig, wenn:** Die VM läuft und du hast den Zustand notiert.

### Aufgabe 3: Erstelle einen Snapshot

1. Suche die Snapshot-Funktion.
2. Erstelle einen Snapshot, wenn es erlaubt ist.
3. Gib ihm einen klaren Namen.
4. Schreibe auf, warum der Snapshot nützlich ist.
5. Wenn Snapshots nicht möglich sind, beschreibe kurz, wie du sichern würdest.

**Fertig, wenn:** Du hast einen Snapshot oder eine Sicherungsnotiz.

### Aufgabe 4: Prüfe Netzwerk vorsichtig

1. Prüfe den Netzwerkmodus der VM.
2. Schreibe auf, ob die VM ins Internet darf.
3. Öffne eine harmlose Webseite, wenn es erlaubt ist.
4. Schreibe auf, ob die Verbindung funktioniert.
5. Ändere keine Netzwerkeinstellungen ohne Erlaubnis.

**Fertig, wenn:** Du hast die Netzwerkverbindung sicher geprüft.

### Aufgabe 5: Schreibe Sicherheitsregeln

1. Schreibe 5 Regeln für sichere VM-Nutzung.
2. Nenne Snapshots.
3. Nenne Netzwerkmodus.
4. Nenne unbekannte Dateien.
5. Nenne Updates.
6. Speichere die Regeln in `vm-sicherheit.md`.

**Fertig, wenn:** Deine VM-Sicherheitsliste ist fertig.

## Extra-Aufgaben

### Extra 1: Netzwerkmodi bewerten

1. Schreibe 2 Netzwerkmodi auf.
2. Schreibe, welcher sicherer für Tests ist.
3. Begründe kurz.

**Fertig, wenn:** Du kannst Netzwerkmodi einfacher einschätzen.

### Extra 2: Export planen

1. Suche, wo man eine VM exportieren kann.
2. Schreibe die Schritte auf.
3. Führe den Export nur aus, wenn es erlaubt ist.

**Fertig, wenn:** Du weißt, wie eine VM gesichert oder übertragen werden kann.

## Reflexion

- Warum sind Snapshots nützlich?
- Welcher Netzwerkmodus ist für Tests sinnvoll?
- Welche VM-Regel willst du immer beachten?

## Speichern oder Abgeben

- Speichere `vm-sicherheit.md`.
- Speichere Snapshot- oder Export-Notizen.
