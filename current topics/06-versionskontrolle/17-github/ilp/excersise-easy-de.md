# Easy ILP: GitHub und Remote-Repositories

## Ziel

Du verbindest ein lokales Git-Repository mit GitHub.

Am Ende hast du:

- ein GitHub-Repository
- eine Remote-Verbindung
- Push und Pull getestet
- ein kleines Synchronisationsprotokoll

## Was du brauchst

- Git
- GitHub-Konto
- lokales Repository
- Terminal

## Basis-Aufgaben

### Aufgabe 1: Repository auf GitHub erstellen

1. Melde dich bei GitHub an.
2. Erstelle ein neues Repository.
3. Gib ihm einen klaren Namen.
4. Mache es nur öffentlich, wenn es erlaubt ist.
5. Kopiere die Remote-URL.

**Fertig, wenn:** Das Repository auf GitHub existiert.

### Aufgabe 2: Remote verbinden

1. Öffne dein lokales Repository im Terminal.
2. Füge die GitHub-URL als Remote hinzu.
3. Prüfe die Remote-Verbindung.
4. Schreibe die Remote-URL in deine Notizen.

**Fertig, wenn:** Lokal und GitHub sind verbunden.

### Aufgabe 3: Push ausführen

1. Prüfe mit `git status`.
2. Stelle sicher, dass deine Änderungen committet sind.
3. Sende deine Commits mit `git push` zu GitHub.
4. Öffne GitHub im Browser.
5. Prüfe, ob die Dateien dort sichtbar sind.

**Fertig, wenn:** Deine Dateien sind auf GitHub.

### Aufgabe 4: Änderung synchronisieren

1. Ändere eine kleine Datei auf GitHub oder lokal.
2. Speichere die Änderung.
3. Synchronisiere mit `pull` oder `push`.
4. Prüfe den Stand an beiden Orten.
5. Schreibe auf, was passiert ist.

**Fertig, wenn:** Lokal und Remote haben denselben Stand.

### Aufgabe 5: Protokoll schreiben

1. Erstelle eine Datei `sync-protokoll.md`.
2. Schreibe die genutzten Befehle hinein.
3. Schreibe auf, was gut funktioniert hat.
4. Schreibe auf, wo es Probleme gab.

**Fertig, wenn:** Dein GitHub-Ablauf ist dokumentiert.

## Extra-Aufgaben

### Extra 1: README verbessern

1. Öffne `README.md`.
2. Ergänze Titel, kurze Beschreibung und Nutzung.
3. Committe und pushe die Änderung.

**Fertig, wenn:** Dein README ist verständlicher.

### Extra 2: Remote-Änderung testen

1. Ändere eine Datei direkt auf GitHub.
2. Hole die Änderung lokal mit `git pull`.
3. Prüfe die Datei lokal.

**Fertig, wenn:** Du hast Pull praktisch getestet.
