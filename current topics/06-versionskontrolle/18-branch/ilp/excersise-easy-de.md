# Easy ILP: Git-Status, Commits und Branches

## Ziel

Du übst wichtige Git-Befehle für Änderungen und Branches.

Am Ende hast du:

- mehrere Commits
- eine wiederhergestellte Datei
- einen Branch
- kurze Git-Notizen

## Was du brauchst

- Git-Repository
- Terminal
- Texteditor

## Basis-Aufgaben

### Aufgabe 1: Status prüfen

1. Öffne dein Git-Repository.
2. Gib `git status` ein.
3. Schreibe auf, ob alles sauber ist.
4. Ändere eine Datei.
5. Gib wieder `git status` ein.
6. Schreibe auf, was sich geändert hat.

**Fertig, wenn:** Du siehst geänderte Dateien im Status.

### Aufgabe 2: Commit erstellen

1. Füge die geänderte Datei mit `git add` hinzu.
2. Prüfe mit `git status`.
3. Erstelle einen Commit mit klarer Nachricht.
4. Prüfe erneut mit `git status`.

**Fertig, wenn:** Die Änderung ist committet.

### Aufgabe 3: Änderung zurückholen

1. Ändere eine Datei absichtlich.
2. Speichere die Datei.
3. Prüfe mit `git diff`.
4. Stelle die Änderung mit einem passenden Git-Befehl zurück.
5. Prüfe den Status.

**Fertig, wenn:** Du kannst eine Änderung zurücknehmen.

### Aufgabe 4: Branch erstellen

1. Zeige vorhandene Branches an.
2. Erstelle einen Branch `test-branch`.
3. Wechsle auf den Branch.
4. Ändere eine Datei.
5. Erstelle einen Commit auf dem Branch.

**Fertig, wenn:** Der neue Branch hat einen eigenen Commit.

### Aufgabe 5: Verlauf ansehen

1. Zeige die Commit-Historie an.
2. Suche deine Commit-Nachrichten.
3. Schreibe auf, welcher Commit auf welchem Branch liegt.

**Fertig, wenn:** Du kannst die Historie grob lesen.

## Extra-Aufgaben

### Extra 1: Zwei Branches testen

1. Erstelle zwei Übungsbranches.
2. Mache auf jedem Branch eine kleine Änderung.
3. Vergleiche die Branches.

**Fertig, wenn:** Du siehst unterschiedliche Arbeitsstände.

### Extra 2: Fehler simulieren

1. Mache eine kleine falsche Änderung.
2. Finde sie mit `git diff`.
3. Stelle sie zurück.

**Fertig, wenn:** Du hast einen Fehler sicher korrigiert.

## Reflexion

- Wann nutzt du `git status`?
- Warum sind Commit-Nachrichten wichtig?
- Wofür ist ein Branch gut?
