# Easy ILP: Git Status, Commits, and Branches

## Goal

You will practise important Git commands for changes and branches.

At the end, you will have:

- several commits
- one restored file
- one branch
- short Git notes

## What You Need

- Git repository
- terminal
- text editor

## Basic Tasks

### Task 1: Check Status

1. Open your Git repository.
2. Type `git status`.
3. Write if everything is clean.
4. Change one file.
5. Type `git status` again.
6. Write what changed.

**Done when:** You see changed files in the status.

### Task 2: Create a Commit

1. Add the changed file with `git add`.
2. Check with `git status`.
3. Create a commit with a clear message.
4. Check again with `git status`.

**Done when:** The change is committed.

### Task 3: Restore a Change

1. Change one file on purpose.
2. Save the file.
3. Check with `git diff`.
4. Restore the change with a fitting Git command.
5. Check the status.

**Done when:** You can undo a change.

### Task 4: Create a Branch

1. Show existing branches.
2. Create a branch `test-branch`.
3. Switch to the branch.
4. Change one file.
5. Create a commit on the branch.

**Done when:** The new branch has its own commit.

### Task 5: View History

1. Show the commit history.
2. Find your commit messages.
3. Write which commit is on which branch.

**Done when:** You can roughly read the history.

## Extra Tasks

### Extra 1: Test Two Branches

1. Create two practice branches.
2. Make a small change on each branch.
3. Compare the branches.

**Done when:** You see different work states.

### Extra 2: Simulate an Error

1. Make one small wrong change.
2. Find it with `git diff`.
3. Restore it.

**Done when:** You corrected an error safely.

## Reflection

- When do you use `git status`?
- Why are commit messages important?
- What is a branch useful for?
