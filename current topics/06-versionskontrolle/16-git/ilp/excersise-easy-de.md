# Easy ILP: Sicher in Git starten

## Ziel

Du richtest Git ein und erstellst dein erstes lokales Repository.

Am Ende hast du:

- geprüfte Git-Installation
- Git-Name und Git-E-Mail
- ein erstes Repository
- einen ersten Commit

## Was du brauchst

- Computer
- Terminal
- Git
- Texteditor

## Basis-Aufgaben

### Aufgabe 1: Git prüfen

1. Öffne das Terminal.
2. Gib `git --version` ein.
3. Schreibe die Version auf.
4. Wenn Git fehlt, melde dich bei deiner Lehrkraft.

**Fertig, wenn:** Du weißt, ob Git installiert ist.

### Aufgabe 2: Git konfigurieren

1. Prüfe deinen Git-Namen.
2. Prüfe deine Git-E-Mail.
3. Setze Name und E-Mail, wenn nötig.
4. Nutze keine falschen Fantasiedaten.
5. Schreibe die Befehle in deine Notizen.

**Fertig, wenn:** Git kennt deinen Namen und deine E-Mail.

### Aufgabe 3: Repository erstellen

1. Erstelle einen Ordner `git_start`.
2. Öffne den Ordner im Terminal.
3. Gib `git init` ein.
4. Prüfe mit `git status`.
5. Schreibe auf, was Git anzeigt.

**Fertig, wenn:** Der Ordner ist ein Git-Repository.

### Aufgabe 4: Erste Datei versionieren

1. Erstelle eine Datei `README.md`.
2. Schreibe 3 kurze Sätze hinein.
3. Prüfe mit `git status`.
4. Füge die Datei mit `git add README.md` hinzu.
5. Prüfe wieder mit `git status`.
6. Erstelle einen Commit.

**Fertig, wenn:** Dein erster Commit existiert.

### Aufgabe 5: Git-Ablauf erklären

1. Schreibe die Begriffe Arbeitsordner, Stage und Commit auf.
2. Erkläre jeden Begriff in einem Satz.
3. Zeichne eine kleine Reihenfolge:
   - ändern
   - add
   - commit

**Fertig, wenn:** Du kannst den Grundablauf erklären.

## Extra-Aufgaben

### Extra 1: Konfiguration ansehen

1. Zeige die Git-Konfiguration an.
2. Schreibe 3 sichtbare Einstellungen auf.

**Fertig, wenn:** Du weißt, wo Git Einstellungen speichert.

### Extra 2: Zweites Repository

1. Erstelle einen zweiten Übungsordner.
2. Initialisiere Git ohne Hilfe.
3. Erstelle eine Datei und einen Commit.

**Fertig, wenn:** Du kannst den Start wiederholen.

## Reflexion

- Was macht `git init`?
- Was macht `git add`?
- Warum sind Commits nützlich?

## Speichern oder Abgeben

- Speichere deine Git-Notizen.
- Behalte dein Übungsrepository.
