# Easy ILP: Start Safely with Git

## Goal

You will set up Git and create your first local repository.

At the end, you will have:

- checked Git installation
- Git name and Git email
- a first repository
- a first commit

## What You Need

- computer
- terminal
- Git
- text editor

## Basic Tasks

### Task 1: Check Git

1. Open the terminal.
2. Type `git --version`.
3. Write down the version.
4. If Git is missing, ask your teacher.

**Done when:** You know if Git is installed.

### Task 2: Configure Git

1. Check your Git name.
2. Check your Git email.
3. Set name and email if needed.
4. Do not use fake data.
5. Write the commands in your notes.

**Done when:** Git knows your name and email.

### Task 3: Create a Repository

1. Create a folder `git_start`.
2. Open the folder in the terminal.
3. Type `git init`.
4. Check with `git status`.
5. Write what Git shows.

**Done when:** The folder is a Git repository.

### Task 4: Version Your First File

1. Create a file `README.md`.
2. Write 3 short sentences in it.
3. Check with `git status`.
4. Add the file with `git add README.md`.
5. Check again with `git status`.
6. Create a commit.

**Done when:** Your first commit exists.

### Task 5: Explain the Git Flow

1. Write the terms working folder, stage, and commit.
2. Explain each term in one sentence.
3. Draw a small order:
   - change
   - add
   - commit

**Done when:** You can explain the basic flow.

## Extra Tasks

### Extra 1: View Configuration

1. Show the Git configuration.
2. Write down 3 visible settings.

**Done when:** You know where Git stores settings.

### Extra 2: Second Repository

1. Create a second practice folder.
2. Initialize Git without help.
3. Create a file and a commit.

**Done when:** You can repeat the start.

## Reflection

- What does `git init` do?
- What does `git add` do?
- Why are commits useful?

## Save or Submit

- Save your Git notes.
- Keep your practice repository.
